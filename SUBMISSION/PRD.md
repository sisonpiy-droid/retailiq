# Product Requirements Document (Updated)
- **Goal**: Build an AI-assisted retail dashboard (RetailIQ).
- **Core Requirements**: 
  - Natural language querying.
  - Multi-tenant data isolation (Store Managers vs. HQ).
  - Secure against SQL Injection and data leakage.
- **Implemented Features**: Hybrid Intelligence (Deterministic + LLM), strict parameterization, intent-based JSON parsing, query caching.
